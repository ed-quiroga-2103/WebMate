Ecuación Cuadrática

Definición 1

Sean \(a, b, c\) y \(d\) constantes reales con \(a ≠ 0\). Se llama ecuación cuadrática o ecuación de segundo grado con una incógnita a toda ecuación que se puede llevar a la forma: $$ax^2 + bx +c = d$$

Ejemplo 1

  1. \(3x^2 - x + 1 = 0\)

  2. \(4x^2 - 1 = 3\)

  3. \(6x^2 + 4x = -1\)

  4. \(x^2 + x +1 = 9\)


Ahora veamos algunos ejemplos resueltos, donde se ilustran algunas técnicas que pueden usar para resolver ecuaciones cuadráticas y algunas ecuaciones que se pueden transformar a la forma cuadrática.

Ejemplo 2

Resuelva cada una de las siguientes ecuaciones:

  1. \(x^2 + 3x = 0\)

    2. Solución $$x^2 +3x = 0$$
    $$x (x + 3) = 0$$
    $$x = 0     ∨    x + 3 = 0$$
    $$x = 0     ∨    x = -3$$
    Por lo tanto el conjunto solución es {0, 3}

  2. \(x^2 - 1 = 0\)

    3. Solución $$x^2 - 1 = 0$$
    $$(x + 1)(x - 1) = 0$$
    $$x + 1 = 0     ∨     x - 1 = 0$$
    $$x = -1     ∨     x = 1$$
    Por lo tanto el conjunto solución es {-1, 1}

  3. \(x^2 - 6x + 9 = 0\)

    4. Solución $$x^2 - 6x + 9 = 0$$
    $$(x - 3)^2 = 0$$
    $$(x - 3)(x - 3) = 0$$ $$x - 3 = 0     ∨     x - 3 = 0$$ $$x = 3     ∨     x = 3$$ Por lo tanto el conjunto solución es {3}

  4. \(x^2 - 9 = -1\)

    5. Solución $$x^2 - 9 = -1$$
    $$x^2 - 9 + 1 = 0$$
    $$x^2 - 8 = 0$$
    $$x^2 - (\sqrt{8})^2 = 0$$
    $$(x - \sqrt{8})(x + \sqrt{8}) = 0$$
    $$x - \sqrt{8} = 0     ∨     x + \sqrt{8} = 0$$ $$x = \sqrt{8}     ∨     x = -\sqrt{8}$$ Por lo tanto el conjunto solución es {\(-\sqrt{8}, \sqrt{8}\)}

  5. \(x^2 + 2x - 3 = 5x - 3\)

    6. Solución $$x^2 + 2x - 3 = 5x - 3$$ $$x^2 + 2x - 3 - 5x + 3 = 0$$ $$x^2 - 3x = 0$$ $$x(x - 3) = 0$$ $$x = 0    ∨     x - 3 = 0$$ $$x = 0     ∨     x = 3$$ Por lo tanto el conjunto solución es {0, 3}

  6. \(4x^2 + 2x = -2x - 1\)

    7. Solución $$4x^2 + 2x = -2x -1$$ $$4x^2 + 2x + 2x + 1 = 0$$ $$4x^2 + 4x + 1 = 0$$ $$(2x + 1)^2 = 0$$ $$(2x + 1)(2x + 1) = 0$$ $$2x + 1 = 0     ∨     2x + 1 = 0$$ $$2x = -1     ∨     2x = -1$$ $$x = \dfrac {-1}{2}     ∨     x = \dfrac{-1}{2}$$ Por lo que el conjunto solución es \(\Bigl\{\dfrac{-1}{2}\Bigr\}\)

Observe que dentro del proceso de resolución de las ecuaciones anteriores hemos usado, según el caso, de los métodos de factorización: factor común y fórmula notable, esto por las características particulares que presentaban las expresiones alebraicas involucradas en cada una de las ecuaciones.

A continuación estudiaremos un procedimiento, que nos permite, es general resolver cualquier ecuación de la forma \(ax^2 + bx + c = d\) con \(a, b, c\) y \(d\) constantes reales con \(a ≠ 0\).

Teorema 1

Sean \(a, b, c\) constantes reales con \(a ≠ 0\), tal que \(ax^2 + bx + c = 0\) y \(∆ = b^2 - 4ac\):

  1. Si ∆ < 0 entonces la ecuación \(ax^2 + bx + c = 0\) no tiene solución en el conjunto de los números reales, es decir el conjunto solución de \(ax^2 + bx + c = 0\) es ∅
  2. Si ∆ = 0 entonces la ecuación \(ax^2 + bx + c = 0\) tiene una única solución, la cual viene dada por \(\dfrac{-b}{2a}\), es decir el conjunto solución de \(ax^2 + bx + c = 0\) es \(\Bigl\{\dfrac{-b}{2a}\Bigr\}\)
  3. Si ∆ > 0 entonces la ecuación \(ax^2 + bx + c = 0\) tiene dos soluciones, las cuales vienen dadas por:
    $$\dfrac{-b - \sqrt{∆}}{2a}    ∨    \dfrac{-b + \sqrt{∆}}{2a}$$ Por lo que el conjunto solución de \(ax^2 + bx + c = 0\) es \(\Biggl\{ \dfrac{-b - \sqrt{∆}}{2a}, \dfrac{-b + \sqrt{∆}}{2a}\Biggr\}\)

Demostración:
  1. Si ∆ < 0 entonces \(ax^2 + bx + c = 0\) no es factorizable en ℝ, es decir \(ax^2 + bx + c ≠ 0\), ∀ x ∈ ℝ
    Por lo que \(ax^2 + bx + c = 0\) no tiene solución en ℝ, o equivalente su conjunto solución es ∅

  2. Si ∆ = 0 entonces: $$ax^2 + bx + c = a\biggl( x + \dfrac{b}{2a} \biggr)^2$$ Por lo que: $$ax^2 + bx + c = 0$$ $$a\biggl( x + \dfrac{b}{2a} \biggr)^2 = 0$$ $$a\biggl( x + \dfrac{b}{2a} \biggr)\biggl( x + \dfrac{b}{2a} \biggr) = 0$$ Luego como a ≠ 0, debe darse que: $$x + \dfrac{b}{2a} = 0     ∨     x + \dfrac{b}{2a} = 0$$ $$x = \dfrac{-b}{2a}     ∨     x = \dfrac{-b}{2a}$$ Por lo que:
    Si ∆ = 0 entonces el conjunto solución de \(ax^2 + bx + c = 0\) es \(\Bigl\{\dfrac{-b}{2a}\Bigr\}\)
  3. Si ∆ = 0 entonces la ecuación \(ax^2 + bx + c = a(x - α)(x - β)\) con α = \(\dfrac{-b - \sqrt{∆}}{2a}\) y β = \(\dfrac{-b + \sqrt{∆}}{2a}\)

    Así tenemos que: $$ax^2 + bx + c = 0$$ $$a(x - α)(x - β) = 0$$ Luego como a ≠ 0, debe darse que:
    $$x - α = 0     ∨     x - β = 0$$ $$ x = α     ∨     x = β$$ y como α = \(\dfrac{-b - \sqrt{∆}}{2a}\) y β = \(\dfrac{-b + \sqrt{∆}}{2a}\)

    entonces \( x = \dfrac{-b - \sqrt{∆}}{2a}\)    ∨     \(x = \dfrac{-b + \sqrt{∆}}{2a}\)

    Por lo que:

    Si ∆ > 0 el conjunto solución de \(ax^2 + bx + c = 0\) es \(\Biggl\{ \dfrac{-b - \sqrt{∆}}{2a}, \dfrac{-b + \sqrt{∆}}{2a}\Biggr\}\)

Ejemplo 3

Resuelva las siguientes ecuaciones:

  1. \(2x^2 + 5x - 12 = 0\)

    2. Solución $$2x^2 + 5x - 12 = 0$$ $$∆ = 5^2 - 4(2)(-12)$$ $$∆ = 25 - (8)(-12)$$ $$∆ = 25 + 96$$ $$∆ = 121$$ Como ∆ > 0, entonces la ecuación correspondiente tiene dos soluciones: $$α = \dfrac{-5 - \sqrt{121}}{2(2)}    ∨     β = \dfrac{-5 + \sqrt{121}}{2(2)}$$ $$α = \dfrac{-5 - 11}{4}    ∨     β = \dfrac{-5 + 11}{4}$$ $$α = \dfrac{-16}{4}    ∨     β = \dfrac{6}{4}$$ $$α = -4     ∨     β = \dfrac{3}{2}$$ Por lo que el conjunto solución es \(\biggl\{ -4, \dfrac{3}{2}\biggr\}\)

  2. \(-x^2 - x + 1 = 0\)

    3. Solución $$-x^2 - x + 1 = 0$$ $$∆ = (-1)^2 - 4(-1)(1)$$ $$∆ = 1 - (-4)$$ $$∆ = 1 + 4$$ $$∆ = 5$$ Como ∆ > 0, entonces la ecuación correspondiente tiene dos soluciones: $$α = \dfrac{-(-1) - \sqrt{5}}{2(-1)}    ∨     β = \dfrac{-(-1) + \sqrt{5}}{2(-1)}$$ $$α = \dfrac{1 - \sqrt{5}}{-2}    ∨     β = \dfrac{1 + \sqrt{5}}{-2}$$ $$α = \dfrac{-1 + \sqrt{5}}{-2}    ∨     β = \dfrac{-1 - \sqrt{5}}{-2}$$ Por lo que el conjunto solución es \(\biggl\{ \dfrac{-1 + \sqrt{5}}{-2}, \dfrac{-1 - \sqrt{5}}{-2} \biggr\}\)

  3. \(2x^2 - 3x + 2 = 0\)

    4. Solución $$2x^2 - 3x + 2 = 0$$ $$∆ = (-3)^2 - 4(2)(2)$$ $$∆ = 9 - 4(4)$$ $$∆ = 9 - 16$$ $$∆ = -7$$ Como ∆ < 0, entonces la ecuación correspondiente no tiene solución en ℝ, por lo que el conjunto solución es ∅

  4. \(x^2 - 1 = x - 2\)

    5. Solución $$x^2 - 1 = x - 2$$ $$x^2 - 1 - x + 2 = 0$$ $$x^2 - x + 1 = 0$$ $$∆ = (-1)^2 - 4(1)(1)$$ $$∆ = 1 - 4$$ $$∆ = -3 $$ Como ∆ < 0, entonces la ecuación correspondiente no tiene solución en ℝ, por lo que el conjunto solución es ∅

  5. \(3x^2 + 3x + 3 = x + 4\)

    6. Solución $$3x^2 + 3x + 3 = x + 4$$ $$3x^2 + 3x + 3 - x - 4 = 0$$ $$3x^2 + 2x - 1 = 0$$ $$∆ = (2)^2 - 4(3)(-1)$$ $$∆ = 4 + 12$$ $$∆ = 16$$ Como ∆ > 0, entonces la ecuación correspondiente tiene dos soluciones: $$α = \dfrac{(-2) - \sqrt{16}}{2(3)}    ∨     β = \dfrac{(-2) + \sqrt{16}}{2(3)}$$ $$α = \dfrac{-2 - 4}{6}    ∨     β = \dfrac{-2 + 4}{6}$$ $$α = \dfrac{-6}{6}    ∨     β = \dfrac{2}{6}$$ $$α = -1     ∨     β = \dfrac{1}{3}$$ Por lo que el conjunto solución es \(\biggl\{ -1, \dfrac{1}{3} \biggr\}\)

  6. \(-2x^2 + 5x - 4 = -x^2 - x + 5\)

    7. Solución $$-2x^2 + 5x - 4 = -x^2 - x + 5$$ $$-2x^2 + 5x - 4 + x^2 + x - 5 = 0$$ $$-x^2 + 6x - 9 = 0$$ $$∆ = (6)^2 - 4(-1)(-9)$$ $$∆ = 36 - 36$$ $$∆ = 0$$ Como ∆ = 0, entonces la ecuación correspondiente tiene una solución: $$α = \dfrac{-6}{2(-1)}$$ $$α = 3$$ Por lo que el conjunto solución es {3}
