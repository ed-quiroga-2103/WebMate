Fracciones Racionales en una Variable

Definición 1

Sean \(P(x)\) y \(Q(x)\) dos polinomios en una variable. La expresión \(\dfrac{P(x)}{Q(x)} \) recibe el nombre de fracción racional , \(P(x)\) recibe el nombre de numerador y \(Q(x)\) recibe el nombre de denominador de la fracción.

Ejemplo 0

$$ a)\ \ \dfrac{x^2-3x+1}{2x-1} \hspace{2cm} b)\ \ \dfrac{x^2-1}{3x^3-2x^2+x-1} \hspace{2cm} c) \dfrac{1}{x^3+1} $$

$$\hspace{1.3cm} d)\ \ \dfrac{x+1}{x+4} \hspace{3.1cm} e)\ \ \dfrac{x^2-9}{x-3} \hspace{4.1cm} f)\ \ \dfrac{x+3(x-1)}{x+3} $$

Simplificación de fracciones racionales

Diremos que una fracción racional está expresada en su forma más simple cuando el numerador y el denominador de dicha fracción no tienen factores comunes. Para simplificar fracciones racionales haremos uso del siguiente resultado:

Si \(P(x), \ Q(x) \) y \(C(x)\) son polinomios entonces se cumple que

\( \dfrac{P(x)\cdot C(x)}{Q(x)\cdot C(x)}=\dfrac{P(x)}{Q(x)} \) para todo \(x\) tal que \(C(x) \neq 0 \)

Ejemplo 1

Simplifique, de ser posible, cada una de las siguientes funciones racionales

$$ a)\ \ \dfrac{2x-6}{2x^2-18} \hspace{3cm} b)\ \ \dfrac{x^3-8}{x^2-4} \hspace{3cm} c)\ \ \dfrac{x^2-4}{x^2-4(x-1)} $$

$$\hspace{-0.1cm} d) \ \ \dfrac{x^3+2x^2-x-2}{x^2-1} \hspace{1.5cm} e) \ \ \dfrac{x^2-9(x-2)}{x-3(x-2)} \hspace{1.6cm} f)\ \ \dfrac{x^2+x-6}{x^2+7x+12} $$

Solución \begin{align*} a)\ \ \dfrac{2x-6}{2x^2-18} &= \dfrac{2(x-3)}{2(x^2-9)}\\ &= \dfrac{2(x-3)}{2(x-3){x+3}}\\ &= \dfrac{1}{x+3}\\ \therefore \dfrac{2x-6}{2x^2-18}&=\dfrac{1}{x+3} \ \ \text{si} \ \ x\neq 3\\\\\\ \end{align*} \begin{align*} b)\ \ \dfrac{x^3-8}{x^2-4} &=\dfrac{(x-2)(x^2+2x+4)}{(x-2)(x+2)}\\ &= \dfrac{x^2+2x+4}{x+2}\\ \therefore \dfrac{x^3-8}{x^2-4}&= \dfrac{x^2+2x+4}{x+2} \ \ \text{si}\ \ x \neq 2\\\\\\ \end{align*} \begin{align*} c)\ \ \dfrac{x^2-4}{x^2-4(x-1)} &= \dfrac{(x-2)(x+2)}{x^2-4x+4}\\ &= \dfrac{(x-2)(x+2)}{(x-2)(x-2)}\\ &= \dfrac{(x+2)}{(x-2)}\\ \therefore \dfrac{x^2-4}{x^2-4(x-1)} &=\dfrac{(x+2)}{(x-2)}\ \ \text{si}\ \ x \neq 2\\\\\\ \end{align*} \begin{align*} d) \ \ \dfrac{x^3+2x^2-x-2}{x^2-1}&= \dfrac{(x^3+2x^2)-(x+2)}{(x-1)(x+1)}\\ &= \dfrac{x^2(x+2)-(x+2)}{(x-1)(x+1)}\\ &= \dfrac{(x+2)(x^2-1)}{(x-1)(x+1)}\\ &= \dfrac{(x+2)(x+1)(x-1)}{(x-1)(x+2)}\\ &= x+2\\ \therefore \dfrac{x^3+2x^2-x-2}{x^2-1}&= x+2\ \ \text{si}\ \ x \neq 1, \ x \neq -1 \\\\\\ \end{align*} \begin{align*} e) \ \ \dfrac{x^2-9(x-2)}{x-3(x-2)} &= \dfrac{x^2-9x+18}{x-3x+6}\\ &= \dfrac{(x-6)(x-3)}{-2x+6}\\ &= \dfrac{(x-6)(x-3)}{-2(x-3)}\\ &= \dfrac{x-6}{-2}\\ \therefore \dfrac{x^2-9(x-2)}{x-3(x-2)} &= \dfrac{x-6}{-2}\ \ \text{si} \ \ x \neq 3 \end{align*} \begin{align*} f)\ \ \dfrac{x^2+x-6}{x^2+7x+12} &= \dfrac{(x+3)(x-2)}{(x+3)(x+4)}\\ &= \dfrac{x-2}{x+4}\\ \therefore \dfrac{x^2+x-6}{x^2+7x+12} &= \dfrac{x-2}{x+4}\ \ \text{si} \ \ x \neq -3 \end{align*}
